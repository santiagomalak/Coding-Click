# Kit del proyecto Coding Click (para Cowork / Claude Code)

Este kit reúne todo el contexto para construir el sitio web de la agencia. Leelo en este orden:

1. `01-brief-proyecto.md` — El encargo completo: qué construir, cómo y en qué orden.
2. `02-packs-y-precios.md` — Catálogo de servicios, packs combinados y reglas comerciales.
3. `03-marca-y-diseno.md` — Marca, paleta, tipografía, motion y sistema visual definitivo para v1.
4. `04-onboarding-clientes.md` — Cómo entra un cliente: desde la consulta hasta la entrega (borrador, a validar con Santiago).
5. `05-pendientes-y-decisiones.md` — Qué falta definir, qué es provisorio y qué ya se decidió.
6. `06-stack-advisor.md` — Especificación de la herramienta interactiva de recomendación de pack.
7. `07-arquitectura-tecnica.md` — Stack técnico, estructura de carpetas y plan de repo/deploy.
8. `marca/` — Logo placeholder y referencias visuales (sumar acá las capturas de Kynesys si hace falta).

## Regla de oro
Antes de escribir código de producción, la estructura, el copy y la dirección visual tienen que estar aprobados por Santiago.

**Estado actual (2026-09-29): dirección visual v1 aprobada** — modo oscuro, acento lima, sistema "tech lab" con esferas físicas, cursor custom y motion GSAP/Lenis. Ver `05-pendientes-y-decisiones.md` para lo que falta cerrar antes de armar el repo definitivo.

## Cómo se actualizó este kit
Los archivos `00`, `02`, `03`, `04`, `05` y `07` se reescribieron el 2026-09-29 para consolidar en un solo lugar todo lo definido en las conversaciones con Cowork: estructura, copy, paleta y el sistema visual "tech lab" (esferas con física, cursor custom, motion GSAP/Lenis) que reemplaza a la paleta violeta de la versión anterior. Es la fuente de verdad para cualquier sesión (Cowork, Claude Code o vos mismo) que retome el proyecto — si algo de acá no coincide con lo que se está construyendo, gana este kit y hay que avisar antes de seguir.
